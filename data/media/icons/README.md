# Icons

Monochrome marks shown on cards and in a thing's history. The page draws
them as a mask in the text colour, so they suit both themes.

- Files named `<slug>.svg` come from [Simple Icons](https://simpleicons.org)
  (CC0 1.0).
- Files named `<slug>-dv.svg` come from [Devicon](https://devicon.dev) (MIT).

Each mark remains the trademark of its owner and is used here only to name
the thing it stands for. Every thing that uses one says so in its `icon`
credit.
